# Fenrir-Wallpapers-03

**Role:** Fenrir public wallpaper gallery only · **Generation:** 2 · **Target:** 1666 images

This repository stores only public gallery image assets and their manifest. It is not a software project repository.

Images are committed only after the private Fenrir Wallpaper Catalog has verified current Public Domain/CC0 rights, source terms, per-asset public publication approval, category, palette, resolution, SHA-256 and duplicate status.

Image paths follow `images/<category-slug>/<sha256>.<extension>`. The manifest is authoritative. Existing local files must never be overwritten or deleted by the desktop sync client.

The fresh gallery is currently empty by design. No image is copied from the previous generation.
