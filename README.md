# Fenrir Wallpapers — Volume 03

This repository is reserved exclusively for image files and their public manifest. It contains no desktop application source, private Catalog assets, credentials or quarantine data.

It is part of the new Fenrir public collection: exactly 5,000 globally unique images across eleven balanced categories and all registered active volumes. Only verified Public Domain or CC0 assets may be published. The 1,871 legacy public image hashes are excluded.

Each image must have source/creator evidence, rights and license metadata, decoded dimensions, byte size, dominant-color metadata and SHA-256 in the canonical manifest. Global uniqueness is enforced by content hash across all volumes.

The system installer consumes the hub registry; this repository has no separate downloader.
